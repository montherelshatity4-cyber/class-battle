# Monther’s Class Battle

A complete, browser-only classroom game show for English students. Teams compete through Grammar, Vocabulary, Speaking, and Challenge rounds with point betting, teacher controls, and a final round.

## Run it

Open `index.html` in a browser, or serve the repository with any static server. No build step, backend, or database is required.

## Included

- 2–4 configurable teams with persistent local browser state
- Large projection-friendly game-show interface
- Question bank separated in `data.js` from game logic in `app.js`
- Grammar and vocabulary multiple choice with explanations
- Speaking prompts with manual teacher award
- 10 / 30 / 50 point betting
- Scoreboard controls for adding/removing points
- Special event card overlay and final leaderboard
- Responsive layout for classroom computers, tablets, and phones

To replace questions, edit the arrays in `data.js`. The application will automatically use the updated content.
